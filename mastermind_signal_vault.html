Rules and difficulty model

A secret sequence is generated from the available color bank. Each guess must contain exactly as many pegs as the selected code width. After submission, the system reports two separate facts.

Exact: correct color in the correct position.
Misplaced: correct color in the wrong position.

Each secret peg can score only once. Exact matches are removed first; misplaced matches are counted from the remaining unmatched pegs. This prevents duplicate colors from producing false extra credit.

Easier modes use fewer colors, a narrower code, more attempts, or no repeated colors. Harder modes use a larger palette, wider codes, fewer attempts, and repeated colors. “Board length” is the vertical number of permitted guesses.

Keyboard control is available: number keys select colors, Backspace removes the last peg, Escape clears the row, and Enter submits a complete guess.
